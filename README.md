## v0.29 로그인 기록 및 영속 저장 개선
- 로그인 성공/실패, 로그아웃, 회원가입 기록을 SQLite `auth_logs` 테이블에 저장합니다. 비밀번호는 로그에 기록하지 않습니다.
- 로그인 후 상단의 `로그인 기록` 메뉴에서 본인 계정의 최근 100건을 확인할 수 있습니다.
- `DATA_DIR` 환경변수로 데이터 저장 경로를 지정할 수 있습니다. 기본값은 프로젝트 내 `data/`입니다.
- **Render 사용 시 주의:** 영구 디스크(Persistent Disk)를 `/var/data`에 마운트하고 환경변수 `DATA_DIR=/var/data`를 설정해야 배포/재시작 후 SQLite DB와 세이브 파일이 유지됩니다. 영구 디스크가 없으면 Render의 임시 파일시스템 때문에 기록이 사라질 수 있습니다. 기존 DB/세이브를 보존하려면 디스크 설정 전에 백업하고, 새 경로로 이전해야 할 수 있습니다.
- 검증: Python 문법 검사, SQLite 테이블/기록 저장 테스트, ZIP 무결성 검사. 실제 Render 배포 테스트는 별도입니다.
