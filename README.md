# 니가 해봐 단장 — Dynasty Web App v0.6 (series schedule + offseason FA + GM trade room)

## 이번 버전에서 실제 작동하는 기능
- 회원가입·로그인·로그아웃 (비밀번호는 Werkzeug 해시로 저장)
- 계정별 독립된 게임 세이브: 한 계정에 활성 세이브 1개, 새 게임 시작 시 해당 계정의 기존 세이브만 교체
- 로그인하지 않으면 게임 메뉴와 API 화면에 접근할 수 없음
- 시작 화면에서 KBO 10개 구단 중 하나를 선택해 2027시즌 게임 시작
- 구단별 전력·초기 현금 차이, 선수단 36명(1군 28명 + 퓨처스 8명) 생성
- 2026시즌 KBO 소속 선수 이름을 팀별 기본 선수단에 반영(구단당 28명)
- 추가 퓨처스 선수·신규 생성 선수·FA 후보는 가상 이름으로 생성
- 선수단 관리: 1군/퓨처스 콜업·말소, 부상 선수 콜업 제한, 엔트리 한도 확인
- 일정: 구단별 144경기를 목표로 한 게임 일정 생성, 한 번에 6경기일씩 리그 자동 시뮬레이션
- 경기 결과·순위·득실·선수 기록·컨디션·피로·부상 업데이트
- FA 시장: 가상 FA 선수 영입 승인, 현금 차감과 연봉 총액 갱신
- 재정: 주간 추정 수입·운영비 반영, 거래 장부 표시
- 프런트/코칭스태프 프로필, 구단 기록실, 세이브 설정 화면
- 기존 18개 규정 후보와 규정 심의 기능 유지
- 모바일 하단 메뉴 및 반응형 화면

## 실행
```bash
pip install -r requirements.txt
python app.py
```

Render 설정:
- Build Command: `pip install -r requirements.txt`
- Start Command: `gunicorn app:app`
- Root Directory: `app.py`가 있는 폴더
- `SECRET_KEY` 환경변수를 설정하는 것을 권장
- `SECRET_KEY` 환경변수는 반드시 강력한 임의 문자열로 설정
- `COOKIE_SECURE=1`을 HTTPS 배포 환경에서 설정
- `data/`를 보존하려면 Render Persistent Disk를 `/opt/render/project/src/data`에 연결. 사용자 계정은 `data/dynasty.db`, 게임 세이브는 `data/games/`에 저장

## 중요한 제한 사항
- 기본 선수단 이름은 2026시즌 KBO 선수단 자료를 바탕으로 반영했습니다. 다만 각 구단의 28명 기본 명단은 게임용 선별 명단이며, 전체 621명 등록 명단을 전부 수록한 것은 아닙니다. 이름 외 능력치·나이·연봉·계약 기간·초기 예산은 시뮬레이션용 추정치이며 실제 선수별 데이터가 아닙니다.
- 퓨처스 추가 선수, 이후 생성되는 신규 선수, FA 시장 후보는 기존 KBO 선수와 구별하기 위한 가상 이름입니다. 실제 신규 선수 영입/신인 드래프트 데이터베이스는 아직 별도 구현되지 않았습니다.
- 일정은 10개 팀이 16회 라운드로빈을 하는 내부 생성 일정입니다. KBO 공식 일정 편성 알고리즘, 우천 취소·더블헤더·포스트시즌은 아직 반영하지 않았습니다. 144경기 목표는 코드상 144 경기일로 구현되어 있습니다.
- 경기 결과는 OVR·컨디션·피로를 반영하는 간략 시뮬레이터이며 실제 야구 기록 분포를 충분히 검증한 엔진은 아닙니다.
- FA는 단순 영입만 지원합니다. 협상, 다년 계약, FA 자격·보상, 트레이드, 드래프트, 외국인/아시아쿼터, 실제 샐러리캡 규정, 은퇴·수상·장기 성장 시스템은 아직 미구현입니다.
- 사용자 계정은 SQLite `data/dynasty.db`에 저장하고 비밀번호는 해시로 보관합니다. 게임 세이브는 JSON 파일이며 SQLite의 `user_games` 테이블이 소유권을 연결합니다. 한 계정에 활성 세이브 하나만 지원하고, 새 게임 생성 시 그 계정의 이전 세이브를 교체합니다. 규정 심의 기록(`data/state.json`)은 아직 전역 공유입니다.
- 공개 서비스 전에는 CSRF 보호, 비밀번호 재설정, 로그인 시도 제한, 계정 삭제/세이브 관리, 규정 상태의 계정별 분리와 실제 Render 배포 테스트가 필요합니다.
- 규정 심의 데모는 기존 `data/state.json`을 사용하므로 해당 규정 기록은 현재 전역 공유입니다. 게임별 세이브와 아직 분리하지 않았습니다.

## Dynasty v0.6 변경 사항
- 정규시즌 일정은 3일 연속 같은 상대를 만나는 3연전 단위로 구성됩니다(팀당 144경기).
- FA 계약은 정규시즌 중 차단되며, 시즌 종료 후 단장이 FA 시장을 열면 21일 동안만 가능합니다.
- FA 시장이 닫힌 뒤 다음 시즌을 시작할 수 있으며 시즌 기록은 시즌 기록 보관함에 남습니다.
- `단장 단톡`에서 타 구단 제안을 확인하고 수락/거절하거나, 우리 구단이 1:1 트레이드를 제안할 수 있습니다.
- 트레이드 성사 시 선수 소속과 양 구단 연봉 총액/거래 장부를 갱신합니다.
- 트레이드 상대 단장의 반응은 선수 OVR 차이를 이용한 시뮬레이션입니다. 다자 트레이드 및 실제 KBO 트레이드 규정은 아직 구현하지 않았습니다.
