# 니가 해봐 단장 — 규정 변경 시스템 프로토타입

## 기능
- 18개 규정 후보 데이터
- 오프시즌 이벤트 발생: 기본 30%
- 이벤트당 안건 1~3개
- 안건별 기본 통과 확률 25~75% 범위
- 단장 찬성/반대 의견에 따른 확률 보정(±8%p, 최종 확률 25~75%로 제한)
- 통과 규정의 다음 시즌 시행 예약
- 심의 이력과 활성/시행 예정 규정 저장
- 모바일 대응 HTML/CSS 화면
- 테스트용 강제 이벤트 생성 버튼

## 실행 방법
Python 3.10 이상 권장.

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS/Linux
source .venv/bin/activate

pip install -r requirements.txt
python app.py
```

브라우저에서 http://127.0.0.1:5000 접속.

## 데이터
`data/state.json`에 현재 시즌, 이벤트 이력, 통과 규정이 저장됩니다. 앱 첫 실행 시 자동 생성됩니다.
대시보드의 초기화 버튼은 데모 데이터를 모두 지우고 2027시즌 상태로 되돌립니다.

## 현재 범위 및 한계
- 이 버전은 전체 야구 단장 시뮬레이션이 아니라 규정 변경 이벤트 모듈의 첫 프로토타입입니다.
- 시즌 진행 버튼은 연도와 규정 시행 상태만 진행합니다. 경기·선수·재정 시뮬레이션은 아직 연결하지 않았습니다.
- 폐지·재개정 안건은 아직 구현되지 않았습니다.
- 개발용 Flask 서버이므로 공개 서비스로 배포하기 전 인증, CSRF 보호, 프로덕션 서버 설정이 필요합니다.
