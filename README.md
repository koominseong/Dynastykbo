# 니가 해봐 단장 Dynasty v0.17

## 실행
```bash
pip install -r requirements.txt
python app.py
```
브라우저에서 http://127.0.0.1:5000 접속.

## v0.17 추가
- 구단주 평가가 2회 연속 45점 미만이면 단장 해임 처리
- 구단·선수단·재정·기록은 유지하고 후임 단장 임명으로 같은 세이브 계속 진행
- 단장 취임·해임 이력 기록

## 참고
해임 조건은 게임용 기본 규칙이며 규칙집에 명시된 공식 수치가 아닌 플레이테스트용 설정이다. Python 문법 검사는 별도로 실행할 수 있다. 실제 Flask 브라우저 통합 테스트는 환경에 따라 별도 확인이 필요하다.


## v0.18 — 게임 오버와 최종 종합 점수

- 커리어 종료 또는 구단주 해임 시 게임 상태를 `종료`로 잠급니다.
- 종료 시 0~1,000점 종합 점수와 등급을 저장합니다.
- 평가 항목: 성적(400), 우승·포스트시즌(200), 장기 운영(100), 재정(150), 육성·팬 관심(100), 구단주 신뢰(50).
- 해임된 커리어는 후임 단장으로 이어가지 않습니다. 새 커리어는 별도로 시작합니다.
- 검증: Python 문법 검사 통과. 실제 브라우저 통합 테스트는 별도 필요.
